# Test

I test automatici sono gestiti separatamente dal componente del gruppo incaricato.
Questo pacchetto conserva soltanto la configurazione runtime: gli output storici e
gli script di test non più allineati al Compose corrente sono stati esclusi.
L'assenza della suite definitiva non è considerata un blocco per l'avvio del
sistema e la cartella è pronta a ricevere i test aggiornati del gruppo.
