En un Centro de Operaciones de Seguridad (SOC) real, esto se conoce como un script de validación de Purple Teaming (mezcla de ataque y defensa).

He consolidado las 8 categorías y las 37 reglas en un solo "Script Maestro". Este script cambiará dinámicamente de "sombrero" (usando al Intruso, al Operador, a la Capitana y al SOC Admin) para probar todos los vectores: Norte-Sur, Este-Oeste, Inspección Profunda (DPI), Exfiltración, y Fuerza Bruta volumétrica.

---

El Script Maestro: test_all_zta_rules.sh
Crea este archivo en la raíz de tu proyecto, dale permisos de ejecución (chmod +x test_all_zta_rules.sh) y
prepárate para ver trabajar a tu motor Snort a toda capacidad.

Qué esperar de esta Auditoría Maestra:
Es un proceso pesado: Tomará aproximadamente 1 minuto y medio ejecutar todo.
Los comandos están optimizados usando & (background) y wait para enviar las ráfagas de Fuerza Bruta y DDOS simultáneamente,
reduciendo el tiempo drásticamente.

No todo será verde ([✔]): Como aprendimos, ver un bloqueo mitigado ([✘] MITIGADO/CIEGO) en pruebas como las de
Movimiento Lateral o Evasión de PEP significa que el Firewall de tu Zero Trust destruyó la amenaza exitosamente.
Snort no generará SIDs para ataques que físicamente no pudieron cruzar el router interno.

El Resultado Final: El archivo de texto resultado_auditoria_completa_zta.txt te brindará un resumen gerencial perfecto para
adjuntar a cualquier reporte técnico o tesis sobre tu proyecto. Demuestra de manera innegable que has testeado cada uno
de los vectores en tu malla ZTA.
